# RiotPixels Provider Evaluation

## Status

RiotPixels is **not enabled** in Phase 10.

## Evidence Required Before Re-evaluation

An implementation may be considered only after all of the following are verified
from authoritative provider documentation or an explicit written agreement:

1. An official API with supported search and metadata access.
2. Explicit media licensing and permission to store or redistribute each media type
   RomM would retain.
3. Published rate limits and an operating policy that complies with them.
4. Required attribution wording, placement, and any logo or link requirements.
5. Credential issuance, storage, rotation, and revocation rules suitable for a
   self-hosted installation.

## Phase 10 Boundary

Phase 10 adds no RiotPixels scraper, adapter, metadata-source enum value, frontend
provider tile, credential setting, or network client. PC metadata review is limited
to already configured providers and the read-only local LaunchBox source.
