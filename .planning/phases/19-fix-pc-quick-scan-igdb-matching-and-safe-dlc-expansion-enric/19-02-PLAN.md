<threat_model>

## Trust Boundaries

| Boundary                                                           | Description                                                                                  |
| ------------------------------------------------------------------ | -------------------------------------------------------------------------------------------- |
| persisted Steam-only ROM to update scan                            | Stored external provider IDs influence whether a database row is considered for repair.      |
| IGDB parent relation to local DLC/expansion metadata               | External metadata can affect component persistence only after exact relationship validation. |
| manual title query and selected candidate to component persistence | User input crosses the review/selection API boundary.                                        |
| scan/storage operations to source library                          | The scan reads source content but must not acquire source write authority.                   |

## STRIDE Threat Register

| Threat ID       | Category               | Component                                | Disposition | Mitigation Plan                                                                                                                                       |
| --------------- | ---------------------- | ---------------------------------------- | ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| T-19-04         | Tampering              | `should_scan_rom` and `fetch_igdb_rom`   | mitigate    | Require all recovery predicates, retain selected-IGDB condition, stored-ID refresh separation, and original-row persistence assertions.               |
| T-19-05         | Tampering              | `_enrich_pc_dlc_from_igdb`               | mitigate    | Require exactly one parent-related IGDB candidate and successful ID hydration before optimistic component write; invoke Steam only afterward.         |
| T-19-06         | Elevation of privilege | `pc_metadata` review/selection endpoints | mitigate    | Preserve existing ROMS_READ review and ROMS_WRITE selection scopes, bounded query validation, candidate ID revalidation, and expected-version checks. |
| T-19-07         | Tampering              | source-library filesystem boundary       | mitigate    | Do not introduce filesystem mutation calls; preserve existing read-only scan and owned-media persistence boundaries.                                  |
| T-19-08         | Denial of service      | provider failure paths                   | accept      | Preserve exception isolation and fail closed when IGDB candidate collection/hydration fails.                                                          |
| T-19-SC         | Tampering              | package installation                     | accept      | No package installation occurs in this phase.                                                                                                         |
| </threat_model> |
