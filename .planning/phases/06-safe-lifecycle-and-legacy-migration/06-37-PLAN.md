Before any cleanup trap is registered or any mutation occurs, each command proves normal application SELECT 1, queries authoritative schema and mysql.user metadata, requires exact database and user@% absence, and requires exact basetemp absence; collision or lookup failure exits without cleanup or mutation. Only then does it install EXIT/INT/TERM cleanup with independent db_owned=0 and user_owned=0 flags, create database and principal separately, prove each exact identity present before setting its flag, and grant only after both flags equal 1. Cleanup revokes/drops the principal only when user_owned=1, drops the database only when db_owned=1, removes only the regex-guarded exact basetemp, preserves the primary status while reporting cleanup failures, and proves final exact DB/user/temp absence plus normal application SELECT 1. Every pytest process receives explicit DB_HOST, DB_PORT, DB_NAME, DB_USER, DB_PASSWD, Redis, ROMM_BASE_PATH, and auth variables plus -p no:env, -p no:cacheprovider, and the exact basetemp. Plan 06-46 Task 2 additionally delegates three-dialect disposable authority to the current checked-in backend/tools/verify_storage_migrations.py contract. Never clean an identity whose owned flag was not established, print credentials, restart services, deploy, or mutate source content.
