## Trust Boundaries

| Boundary                        | Description                                                           |
| ------------------------------- | --------------------------------------------------------------------- |
| caller to owned descriptor      | Bytes cross into a root-bounded write capability                      |
| temporary file to destination   | Replace becomes visible only at os.replace                            |
| kernel result to mutation state | Short, interrupted, or failed writes are untrusted completion signals |

| Threat ID       | Category               | Component            | Disposition | Mitigation Plan                                                                      |
| --------------- | ---------------------- | -------------------- | ----------- | ------------------------------------------------------------------------------------ |
| T-06-31-01      | Tampering              | OwnedCreate.create   | mitigate    | Write all bytes and remove only the new destination on failure                       |
| T-06-31-02      | Tampering              | OwnedReplace.replace | mitigate    | Keep old content until a fully written and fsynced temporary file reaches os.replace |
| T-06-31-03      | Denial of service      | write loop           | mitigate    | Reject zero or invalid progress and retry only InterruptedError                      |
| T-06-31-04      | Elevation of privilege | cleanup              | mitigate    | Retain descriptor-relative, no-follow, root-bounded cleanup                          |
| T-06-31-05      | Information disclosure | errors               | mitigate    | Preserve bounded error translation without resolved host paths                       |
| </threat_model> |
