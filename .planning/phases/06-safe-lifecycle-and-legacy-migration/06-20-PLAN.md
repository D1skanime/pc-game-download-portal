## Trust Boundaries

| Boundary                         | Risk                                                          | Disposition | Mitigation                                                                 |
| -------------------------------- | ------------------------------------------------------------- | ----------- | -------------------------------------------------------------------------- |
| 0111 data to 0112 constraints    | Fingerprintless selection remains authority or blocks upgrade | mitigate    | Invalidate before constraint creation and version-bump stale confirmations |
| STAT to HASH                     | File replacement consumes bytes beyond the aggregate budget   | mitigate    | Pass remaining cap and reject returned overage                             |
| Alembic to non-transactional DDL | MariaDB/MySQL fail after partial schema work                  | mitigate    | Data normalization precedes constraints; downgrade guards precede DDL      |
| verifier to Docker               | Named resources leak or target unrelated containers           | mitigate    | UUID-owned dialect containers and exact-name cleanup in finally            |
| errors to API/log                | Source paths or raw DB diagnostics leak                       | mitigate    | Stable problem code and verifier secret/path redaction                     |
