<threat_model>

## Attack Surface

Administrator confirmations, mutable catalog state, mutable external directories, and cross-dialect migration state.

## Trust Boundaries

| Boundary                  | Risk                                                                                 | Mitigation                                                                                                                  |
| ------------------------- | ------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| detection to confirmation | Equal-metadata byte substitution is accepted                                         | Persist a complete path/type/size/content digest and reobserve through trusted LIST/STAT/HASH capabilities                  |
| client to DB mutation     | Counts are replayed or substituted                                                   | Bind result/version/platform/root/path plus source and exact catalog fingerprints                                           |
| filesystem to digest      | Ordering, symlink, short-read, concurrent-write, or budget manipulation creates gaps | Domain-separate sorted records, hash every regular-file byte, and reject unsafe/incomplete observations before confirmation |
| Alembic across dialects   | Partial DDL or lossy downgrade corrupts authority                                    | Named portable schema and pre-DDL guards on all supported dialects                                                          |

## Abuse Cases and Security Verification

- Equal-count catalog substitutions and equal-path/type/size/metadata byte substitutions fail.
- Replay, cross-platform, expired, symlink, short-read, concurrent-change, and every explicit budget-exhaustion case write nothing.
- Digest tests include content changes, record-boundary collision attempts, enumeration-order changes, and deterministic reruns.
- Closed inventory proves LIST/STAT/HASH only, source manifests remain identical, and no mutation operation is authorized.
  </threat_model>
