<threat_model>

## Attack Surface

Destructive v2 dialog events, client request construction, partial bulk outcomes, and user-visible safety claims.

## Trust Boundaries

| Boundary                       | Risk                                                  | Mitigation                                                                                      |
| ------------------------------ | ----------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| UI event to API client         | Hidden state or stale code sends forbidden source IDs | Remove the state and argument from the TypeScript interface, then assert the exact request body |
| API response to gallery stores | Partial failure removes unprocessed items locally     | Retain failed-ID reconciliation and test mixed outcomes                                         |

## Abuse Cases and Security Verification

- Component tests prove no filesystem action can be reached by pointer, keyboard, or gamepad because the control is absent.
- Service tests/types prove callers cannot encode `deleteFromFs`.
- Backend remains the authority; existing direct-call source mutation denials remain part of final closure.
  </threat_model>
