<threat_model>

## Trust Boundaries

| Boundary                                 | Risk                                                                  | Disposition | Mitigation                                                                             |
| ---------------------------------------- | --------------------------------------------------------------------- | ----------- | -------------------------------------------------------------------------------------- |
| scan observation to retained identity    | Weak or attacker-controlled metadata claims another game's user value | mitigate    | Exact normalized logical path first, otherwise one unique complete triple hash         |
| ROM persistence to reconnect transaction | Crash between commits strands retained value                          | mitigate    | Durable idempotent reconnect runs for new and already-existing exact matches           |
| concurrent scanners to database          | Two ROMs split ownership                                              | mitigate    | Lock target and retained candidates in deterministic order; conditional updates        |
| database to external storage             | Retry reopens or mutates source                                       | mitigate    | Reconnect uses persisted identities only and has no descriptor or filesystem authority |

## STRIDE Threat Register

| Threat ID       | Category               | Component               | Disposition | Mitigation Plan                                                                         |
| --------------- | ---------------------- | ----------------------- | ----------- | --------------------------------------------------------------------------------------- |
| T-06-19-01      | Spoofing               | scan identity           | mitigate    | Reject basename, provider ID, partial hash, alias, and first-match behavior             |
| T-06-19-02      | Tampering              | retained ownership rows | mitigate    | Move all three ownership families in one transaction                                    |
| T-06-19-03      | Repudiation            | retry outcome           | mitigate    | Tests assert exact retained version and active_rom_id transitions                       |
| T-06-19-04      | Information disclosure | errors/logs             | mitigate    | Keep bounded IDs and omit source/asset paths                                            |
| T-06-19-05      | Denial of service      | repeated scan retry     | accept      | Idempotent no-op after success and platform-bounded candidate query                     |
| T-06-19-06      | Elevation of privilege | hidden retained assets  | mitigate    | Reconnection changes ownership only; existing asset authorization remains authoritative |
| </threat_model> |
