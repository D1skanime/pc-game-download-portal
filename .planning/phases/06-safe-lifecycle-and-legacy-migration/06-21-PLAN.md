## Trust Boundaries

| Boundary                                 | Risk                                                | Disposition | Mitigation                                                                   |
| ---------------------------------------- | --------------------------------------------------- | ----------- | ---------------------------------------------------------------------------- |
| catalog row creation to durable identity | Reused ID/timestamp reproduces a prior row          | mitigate    | Private random token overwritten on every insert and immutable afterward     |
| rollback token to live catalog           | Stale ID targets a reparented or substituted entity | mitigate    | Lock exact persisted entity/parent tokens and validate before any write      |
| old 0112 data to 0113                    | Historical lineage is unknowable                    | mitigate    | Fail-safe invalidate rollback eligibility; never backfill from current state |
| Alembic across dialects                  | FK/index/DDL ordering leaves partial schema         | mitigate    | Staged portable columns, named constraints, pre-DDL downgrade guard          |
| rollback to source storage               | Recovery mutates external bytes                     | mitigate    | No descriptor construction or filesystem call; manifest equality tests       |

| T-06-21-02      | Tampering              | same-platform reparent   | mitigate    | Persist parent ID/incarnation at migration and compare under locks         |
