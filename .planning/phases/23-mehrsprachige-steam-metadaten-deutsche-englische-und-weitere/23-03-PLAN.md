<interfaces>
From `frontend/src/stores/language.ts`, UI locales use underscore-form tags such as `de_DE` and `en_US`; presentation must reduce them to a lower-case base tag.

From the detail payloads:

```typescript
type DetailedRomSchema = {
  summary: string | null;
  steam_metadata: SteamMetadataSchema | null;
};
type PcComponentMetadataSchema = {
  summary: string | null;
  steam_metadata: SteamMetadataSchema | null;
};
```

The resolver contract is:

```typescript
resolveSteamTextVariant({ steamMetadata, legacySummary, locale, steamSummaryIsAuthoritative }): string | null
```

It selects an eligible Steam-owned `locale` base variant, then `en`, then `legacySummary`; callers must pass false when manual or another provider owns the persisted display field.
</interfaces>
