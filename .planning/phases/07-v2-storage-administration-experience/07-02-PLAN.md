<objective>
Build the accessible v2 root overview and one-page guided mapping workflow.

Purpose: administrators can understand existing roots, browse safely within a root, test a proposed mapping, and save only after success.
Output: root list/detail views and a guided mapping editor using the shared foundation from Plan 07-01.
</objective>
