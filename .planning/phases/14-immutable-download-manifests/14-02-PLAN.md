<threat_model>

## Trust Boundaries

| Boundary                                | Description                                                                                      |
| --------------------------------------- | ------------------------------------------------------------------------------------------------ |
| User/ROM selection to aggregate service | User-provided IDs request server-side selection but cannot identify paths or foreign components. |
| Aggregate service to external library   | Current source evidence is re-read through a constrained HASH capability.                        |

## STRIDE Threat Register

| Threat ID       | Category               | Component             | Disposition | Mitigation Plan                                                                                                                                                      |
| --------------- | ---------------------- | --------------------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| T-14-06         | Information disclosure | capture helper        | mitigate    | Return only path-free destination and evidence. Tests assert raw NAS/container/source paths and raw OSErrors never escape.                                           |
| T-14-07         | Elevation of privilege | `get_manifest`        | mitigate    | Every retrieval includes `user_id` in the query. Handler tests prove another authenticated user's ID cannot retrieve the header.                                     |
| T-14-08         | Information disclosure | selection resolver    | mitigate    | Foreign, hidden-at-route, absent, and unsupported components are rejected by ID and bounded handler outcomes, preventing component enumeration.                      |
| T-14-09         | Tampering              | selection transaction | mitigate    | Deterministic row locks, unique constraints, de-duplicated request validation, and capture-before-insert prevent unsafe or mixed partial selections.                 |
| T-14-10         | Tampering              | source resolution     | mitigate    | Persisted member-only input, canonical relative validation, descriptor HASH access, no-follow policy, and adversarial unsafe-path/symlink tests prevent path escape. |
| T-14-11         | Tampering              | snapshot lifecycle    | mitigate    | Revalidate every member, use strong quoted snapshots distinct from SHA-256, and persist SOURCE_CHANGED rather than allowing mixed evidence; expiry remains EXPIRED.  |
| T-14-12         | Tampering              | external source root  | mitigate    | The only filesystem operation is HASH. Tests capture before/after fixture state and assert no source writes, sidecars, archives, or temp data.                       |
| T-14-SC         | Tampering              | package installs      | accept      | No package-manager install is in this plan.                                                                                                                          |
| </threat_model> |
