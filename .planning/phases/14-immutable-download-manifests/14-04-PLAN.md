<threat_model>

## Trust Boundaries

| Boundary                                    | Description                                                                                                  |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| Trusted source evidence to durable manifest | Source component/member IDs and captured bytes become an immutable aggregate that later authorizes delivery. |
| Durable manifest to public JSON             | Internal row keys and source identifiers cross into an untrusted client-visible contract.                    |
| Ordinary GET to filesystem metadata         | A requester triggers lifecycle checks that must not become bulk content hashing or transfer.                 |

## STRIDE Threat Register

| Threat ID | Category               | Component                  | Disposition | Mitigation Plan                                                                                                                                          |
| --------- | ---------------------- | -------------------------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| T-14-20   | Tampering              | snapshot construction      | mitigate    | Allocate the opaque public ID before capture and test the exact NUL-separated strong snapshot formula with that same persisted value.                    |
| T-14-21   | Tampering              | ORM/database aggregate     | mitigate    | Enforce selected-component/source-member ownership with named composite unique keys and foreign keys, and prove the direct cross-component insert fails. |
| T-14-22   | Information disclosure | manifest serializer        | mitigate    | Expose only public UUID `file_id` and its relative future URL; endpoint tests reject internal/source IDs and path fields.                                |
| T-14-23   | Denial of service      | ordinary manifest GET      | mitigate    | Preserve STAT-only light revalidation and regress against `open_rom_hash` on normal retrieval.                                                           |
| T-14-24   | Elevation of privilege | future delivery identifier | mitigate    | Keep the URL a relative opaque identifier only, with no handler or transfer grant in Phase 14; Phase 15 must reauthorize and revalidate before transfer. |
| T-14-25   | Tampering              | source library             | mitigate    | Capture retains HASH-capability read-only behavior and tests add no source writes, temp files, archives, or delivery code.                               |
| T-14-SC   | Tampering              | package installs           | accept      | No package-manager installation is in this plan.                                                                                                         |

</threat_model>
