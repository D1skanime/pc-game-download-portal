## STRIDE Threat Register

| Threat ID       | Category               | Component                  | Disposition | Mitigation Plan                                                                                                                                      |
| --------------- | ---------------------- | -------------------------- | ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |

| T-14-02         | Elevation of privilege | owner association          | mitigate    | Non-null `user_id` FK and owner-scoped retrieval planned in 14-02; model tests prove owner is mandatory and cascade-safe.                            |
| T-14-03         | Tampering              | component/member selection | mitigate    | Named FK and uniqueness constraints preserve one immutable selection topology and disallow duplicate or mixed member rows.                           |
| T-14-04         | Tampering              | lifecycle status           | mitigate    | Portable closed enum records VALID, EXPIRED, REVOKED, and SOURCE_CHANGED separately; API status transitions are tested in 14-02.                     |
| T-14-05         | Tampering              | source root                | mitigate    | Migration and models create only DB objects. Focused evidence asserts no source fixture mutation; no filesystem path or capability is accepted here. |
| T-14-SC         | Tampering              | package installs           | accept      | No package-manager install is in this plan.                                                                                                          |
