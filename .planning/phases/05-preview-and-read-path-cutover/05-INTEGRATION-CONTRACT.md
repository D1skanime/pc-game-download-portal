## Required Data Flow

1. Load mapping from DBStorageHandler.
2. Compare mapping id, version, active before filesystem access and at D-11 safe boundaries.
3. Load StorageRoot, obtain live StorageRootHealthSnapshot, fail visibly when unsafe.
4. Resolve stored relative_path through resolve_directory.
5. Bind trusted descriptor and authorize exact StorageOperation.
6. Open one operation-specific capability through open_storage_access.
7. Revalidate immediately before response, file handle, or internal redirect.
8. Persist preview results only through Plan 05-04 fallback in RomM-owned database storage.
