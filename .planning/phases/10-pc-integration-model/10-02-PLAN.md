<objective>
Provide a review-first PC metadata API over existing configured providers and a
read-only local LaunchBox source, plus an explicit no-enable RiotPixels evaluation.
</objective>

<threat_model>

- Assets: provider credentials, selected game metadata/media, local LaunchBox files,
  and external PC roots.
- Threats: automatic wrong-match write, SSRF/untrusted media URL, provider outage,
  credential disclosure, and unlicensed RiotPixels scraping.
- Controls: candidate search is read-only; apply requires an explicit candidate ID;
  route uses authenticated ROM visibility checks; reuse provider adapter allowlists;
  local LaunchBox access is read-only; RiotPixels has no adapter, credential, or
  runtime source registration.
  </threat_model>
