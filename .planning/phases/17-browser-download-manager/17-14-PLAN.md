# Phase 17 Hardening execution

Objective: execute the approved release hardening plan in dependency order. Do not begin Phase 18 or touch real NAS, Team4s, deployment, or source-root writes.

## Task 1: State and attempt authority

Write failing transition and reconciliation tests. Add explicit session status/result semantics, terminal timestamps, owner-scoped attempt lineage, member-restricted retry, and one locked reconciliation function. Add a portable migration and run isolated database tests.

## Task 2: Attributed member streaming

Write full GET, Range, mismatch, disconnect, and owner-masking tests. Bind requests to an authorized session item and record only proven response byte coverage. Range completion must not mean full member served.

## Task 3: Large-source revalidation

Write source replacement, truncation, identity drift, expiry, and Range-resume tests. Replace pre-stream full hashing with descriptor-bound structural checks against captured size, mtime_ns, device, inode, strict snapshot continuity, and final enhanced SHA validation. Record isolated first-byte and source-I/O evidence.

## Task 4: Enhanced FSA lifecycle

Write pause/cancel/network/permission/checksum tests. Track explicit abort intent, close writer on pause, use actual persisted bytes for resume, locally rehash persisted bytes before remaining stream, and persist verified only after exact closed-file digest validation.

## Task 5: Durable retry and history

Add owner-scoped retry/remove contracts and tests. A retry creates a linked attempt containing only failed/cancelled/stale members. Rehydrate active and historical attempts independently; never use a UI timeout for history removal.

## Task 6: Standard handoff truthfulness

Test one, ten, and eighty selected members. Replace false browser-concurrency claims with explicit user-controlled handoff batches and accurate handed-to-browser/served language.

## Task 7: Manager UX and performance

Build active plus history sections, component grouping, valid row actions, responsive bulk actions, accessible status text, and throttled progress persistence. Measure 80-member DOM, reactivity, API calls, and memory before virtualizing.

## Task 8: Automated and live gates

Run database tests through an isolated MariaDB service. Add browser automation. Perform real isolated Chrome, Edge, and Firefox standard handoff and enhanced large/multi-file UAT. Capture source fingerprint, access-time, I/O, first byte, resume offset, final SHA, and screenshots. Update verification only when all evidence passes.

## Verification

Run focused backend and frontend suites after each task, then complete frontend typecheck/build, migration checks, automated browser tests, and the isolated live evidence matrix. Commit only files belonging to this plan; never include existing unrelated working-tree changes.
