must_haves:

- The user can see and edit the description for the selected locale from the existing detail surface.
- The UI clearly shows manual, provider, and fallback provenance and offers save, cancel, and clear/reset states.
- The same interaction works for parent games, DLCs, and expansions without separate feature implementations.
- All new strings have complete locale parity and the control is usable by keyboard, mouse, and touch in light and dark themes.
- Detail navigation presents Overview, PC Game Download or classic Patcher, Media, and Files in that order before secondary tabs.
- The PC Game Download local-media action is labeled by its actual behavior and is clearly distinct from online cover search.
- Media screenshots expose a complete delete action for authorized users, not only placement removal from Overview or Background.
- Cover search is discoverable, clearly labeled, and explains provider availability and result provenance.
- Crawled release date and genres are visible separately from manual overrides, while manual edits remain explicit and persistent.
- A saved YouTube video ID has a visible, validated result in the Overview media area.
- File locations shown in edit and file surfaces use the active mapped storage root and clearly distinguish logical paths from host/container paths.
- For PC ROMs, the header download action opens the existing Game Download screen, and the copy-download-link action is hidden.
- DLC and expansion details have a component-scoped Game Download tab that reuses the existing download selection contract.
- Component Media supports Overview placement and complete deletion without exposing parent-game media; DLC/Expansion media cannot replace the parent-game background.
- Overview media is clickable and opens the existing gallery/viewer interaction for the selected DLC/Expansion.
- A component-scoped edit action is available from the DLC/Expansion overflow menu and saves through the existing ROM-like metadata editor contract.
- The DLC/Expansion edit menu exposes the same component-scoped cover search as the main game, including provider status and result provenance.
- Component Files shows only manifest members from the selected DLC/Expansion; media is not mixed into the file list.
<objective>Add the localized manual metadata editor and clear media/provider interactions to the existing v2 detail surfaces.</objective>
