<threat_model>

## Trust Boundaries

| Boundary                                    | Description                                                                                         |
| ------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| Application authorization to nginx delivery | A DB-authorized read becomes an internal redirect and must not become a public raw filesystem path. |
| Application request to worker queue         | Durable scan and metadata work crosses from app to worker and must stay on the isolated stack.      |
| Restarted stack to persisted evidence       | Stack restarts must preserve only intended owned state and not rewrite the source fixture.          |

| Threat ID       | Category               | Component           | Disposition | Mitigation Plan                                                                                                     |
| --------------- | ---------------------- | ------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------- |

| T-09-05         | Tampering              | Workflow envelopes  | mitigate    | Write separate before/after/diff/result artifacts per workflow and reject missing or cross-linked identities.       |
| T-09-06         | Information Disclosure | Internal file paths | mitigate    | Keep negative direct-path probes, 404-masking, and bounded result fields in integration coverage.                   |
| </threat_model> |
