- Steam media is reviewable/priority input only. It never calls selected-artwork storage with implicit overwrite and does not overwrite manual or explicitly selected media.

Add Steam to PC candidate providers and candidate fields, resolving a manually selected App ID to details before application rather than trusting search-list payloads. Add a narrow stored-ID-first scan fetch using `meta_steam_handler`, isolate any exception as an empty Steam result, and add it to the scan metadata handler map only for PC-eligible flows. Use existing priority code only for candidate artwork input; do not grant Steam generic precedence over IGDB relationships. Per D-02, D-04, and D-06, use structured bounded logs and never make `steam_metadata` a display-state fallback.</implementation>

## Trust Boundaries

| Boundary                                   | Description                                                                                            |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------ |
| Provider match to existing ROM             | A remote identity and text must not replace a manually maintained catalog record.                      |
| Candidate-selection request to persistence | User-selected candidate IDs and media IDs are untrusted request values until server-side recollection. |

## STRIDE Threat Register

| Threat ID       | Category               | Component             | Disposition | Mitigation Plan                                                                                                  |
| --------------- | ---------------------- | --------------------- | ----------- | ---------------------------------------------------------------------------------------------------------------- |
| T-18-11         | Spoofing               | automatic Steam match | mitigate    | Refresh persisted IDs by ID, platform-gate search, require existing similarity logic, and never locale-research. |
| T-18-12         | Tampering              | Steam merge           | mitigate    | One pure non-empty normalizer guards manual and IGDB-owned fields for scan and manual paths.                     |
| T-18-13         | Elevation of privilege | PC selection API      | mitigate    | Recollect candidates server-side under existing ROMS_READ/ROMS_WRITE scopes and optimistic update checks.        |
| T-18-14         | Information disclosure | artwork/media         | mitigate    | Reuse existing owned-media selection path; no direct filesystem path writes from remote Steam URLs.              |
| </threat_model> |
