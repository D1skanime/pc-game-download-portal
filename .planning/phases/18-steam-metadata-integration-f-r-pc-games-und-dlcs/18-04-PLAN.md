## Trust Boundaries

| Boundary                                   | Description                                                                                            |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------ |
| Provider match to existing ROM             | A remote identity and text must not replace a manually maintained catalog record.                      |
| Candidate-selection request to persistence | User-selected candidate IDs and media IDs are untrusted request values until server-side recollection. |

## STRIDE Threat Register

| Threat ID       | Category               | Component             | Disposition | Mitigation Plan                                                                                                  |
| --------------- | ---------------------- | --------------------- | ----------- | ---------------------------------------------------------------------------------------------------------------- |
| T-18-11         | Spoofing               | automatic Steam match | mitigate    | Refresh persisted IDs by ID, platform-gate search, require existing similarity logic, and never locale-research. |
| T-18-12         | Tampering              | Steam merge           | mitigate    | One pure non-empty normalizer guards manual and IGDB-owned fields for scan and manual paths.                     |
| T-18-13         | Elevation of privilege | PC selection API      | mitigate    | Recollect candidates server-side under existing ROMS_READ/ROMS_WRITE scopes and optimistic update checks.        |
| T-18-14         | Information disclosure | artwork/media         | mitigate    | Reuse existing owned-media selection path; no direct filesystem path writes from remote Steam URLs.              |
| </threat_model> |
