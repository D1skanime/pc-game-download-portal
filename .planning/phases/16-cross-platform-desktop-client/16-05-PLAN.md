## Trust Boundaries

| Boundary                   | Description                                                                     |
| -------------------------- | ------------------------------------------------------------------------------- |
| webview to Tauri commands  | rendered UI is untrusted relative to native filesystem and credential authority |
| device flow to token store | a bearer token grants current user read access                                  |

## STRIDE Threat Register

| Threat ID       | Category               | Component                   | Disposition | Mitigation Plan                                                                                                  |
| --------------- | ---------------------- | --------------------------- | ----------- | ---------------------------------------------------------------------------------------------------------------- |
| T-16-16         | Elevation of privilege | Tauri commands/capabilities | mitigate    | typed narrow commands delegate only to core; prohibit arbitrary shell, path, network, and token methods          |
| T-16-17         | Information disclosure | auth adapter                | mitigate    | OS credential store only, redacted DTOs/logging, origin-bound device flow                                        |
| T-16-18         | Spoofing               | device authorization        | mitigate    | use existing init/poll contract, exact configured origin, expiry/interval enforcement, `ROMS_READ` minimum scope |
| T-16-19         | Tampering              | release configuration       | mitigate    | explicit Windows/Linux capabilities and command-boundary tests, no ambient broad permissions                     |
| </threat_model> |
