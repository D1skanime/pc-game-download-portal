## Trust Boundaries

| Boundary                                     | Description                                                       |
| -------------------------------------------- | ----------------------------------------------------------------- |
| user/webview actions to native command state | UI must not create an alternate unsafe file or authorization path |
| recovery presentation to user decision       | unclear state can cause accidental data loss or unsafe overwrite  |

## STRIDE Threat Register

| Threat ID       | Category               | Component           | Disposition | Mitigation Plan                                                                                               |
| --------------- | ---------------------- | ------------------- | ----------- | ------------------------------------------------------------------------------------------------------------- |
| T-16-20         | Elevation of privilege | UI command use      | mitigate    | invoke only typed Plan-16-05 commands, no raw filesystem/network/token bridge                                 |
| T-16-21         | Tampering              | local conflict UX   | mitigate    | explicit three-choice conflict state, no default replace invocation                                           |
| T-16-22         | Information disclosure | UI state            | mitigate    | render redacted state/opaque IDs only, never source paths, headers, or device token                           |
| T-16-23         | Repudiation            | recovery actions    | mitigate    | show exact core state and explicit user action outcome; core owns durable job state                           |
| T-16-24         | Tampering              | UAT evidence        | mitigate    | executable real-engine loopback gate records exact range/hash/finalization/cleanup, never a /dev/null sink    |
| T-16-25         | Denial of service      | platform completion | mitigate    | blocking Windows, Linux, and Bazzite evidence gate; missing authorized runner leaves phase blocked/incomplete |
| </threat_model> |
