  <behavior>
    - Free-space preflight calculates sum of expected `u64` bytes minus only valid matching partial bytes plus conservative `max(2 GiB, configured 2-5%)` margin. It must not promise disk-full cannot occur later.
    - Streamed or completed parts are verified against the persisted SHA-256 before completion. A mismatch becomes `CHECKSUM_FAILED`, retains a non-promoted part/job for recovery decision, and never publishes a final.
    - Normal finalization only follows complete hash match: fsync sibling part, atomically rename it to a final target confirmed nonexistent on the same filesystem, then persist `COMPLETED` atomically.
    - Final mismatch becomes `LOCAL_CONFLICT`; default behavior offers no overwrite. An explicit overwrite downloads and verifies a fresh sibling part first, then calls a distinct platform-aware transactional replace operation. Test normal no-replace and approved replace separately under Linux and Windows compatibility adapters.
    - Classify ENOSPC as `DISK_FULL`, permission failures as `PERMISSION_DENIED`, interrupted transport as `NETWORK_ERROR`, and pause as `PAUSED`, preserving exact safe job state, local path ownership, and recovery action without deleting a good final.
  </behavior>

## Trust Boundaries

| Boundary                                 | Description                                                              |
| ---------------------------------------- | ------------------------------------------------------------------------ |
| downloaded part to final namespace       | incomplete/corrupt bytes must never acquire a trusted final filename     |
| user conflict decision to replacement    | overwrite is privileged local intent, not a default transfer side effect |
| filesystem capacity/errors to job engine | local OS conditions can change after preflight                           |

| </threat_model> |
