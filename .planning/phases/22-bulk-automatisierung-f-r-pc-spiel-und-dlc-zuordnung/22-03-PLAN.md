<threat_model>

## Trust Boundaries

| Boundary                               | Description                                                     |
| -------------------------------------- | --------------------------------------------------------------- |
| browser to queue API                   | Queue IDs, versions, filters, and batch requests are untrusted. |
| queue API to ROM/component persistence | An API request may race an operator or a scan.                  |

## STRIDE Threat Register

| Threat ID       | Category               | Component                       | Disposition | Mitigation Plan                                                                                                                  |
| --------------- | ---------------------- | ------------------------------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------- |
| T-22-07         | Spoofing               | Queue endpoints                 | mitigate    | Existing authenticated `protected_route` scopes guard reads and mutations.                                                       |
| T-22-08         | Elevation of privilege | Queue listing and batch actions | mitigate    | Assert target visibility after server reload for each list item and every batch member.                                          |
| T-22-09         | Tampering              | Accept and batch payloads       | mitigate    | Ignore client candidate metadata; validate pending state, target kind, fingerprint, versions, and manual protection server-side. |
| T-22-10         | Repudiation            | Queue transitions               | mitigate    | Store terminal state, transition timestamps, and action outcome on durable queue rows.                                           |
| T-22-SC         | Tampering              | npm/pip installs                | accept      | No new package is installed.                                                                                                     |
| </threat_model> |
