<objective>
Create a manifest-bound, review-first backend contract for selected local PC
artwork, including owned-resource copies and rescan reconciliation, without
giving the external library any write path.
</objective>

<threat_model>

- Assets: immutable external image bytes, component identity, SHA-256 evidence,
  RomM-owned resources, and existing selected cover state.
- Threats: path traversal, extension spoofing, source changes after review,
  archive/PDF promotion, source mutation, and deletion outside owned storage.
- Controls: use persisted component/member IDs rather than host paths; enumerate
  only DLC/extra manifest members; validate real MIME plus image decodability;
  re-hash immediately before copy; write/clean only through `FSResourcesHandler`;
  reject stale expected versions and changed manifest evidence.
- Blocking proof: before/after source-tree digests remain byte-identical through
  discovery, preview, apply, and rescan; only RomM resource paths are created or
  removed.
  </threat_model>
