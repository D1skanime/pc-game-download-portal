<objective>
Expose independent DLC review and selected local artwork in the v2 game-details
experience, with Files-tab internal DLC navigation and no IGDB fallback for
DLC/expansion cards.
</objective>

<threat_model>

- Assets: operator confidence in base versus DLC metadata, owned local artwork,
  component-file navigation, and browser trust.
- Threats: silently applying metadata, exposing an unsafe source path, confusing
  a DLC with the base game, stale UI after apply, and external navigation from a
  DLC card.
- Controls: generated typed API contracts; disabled apply until exactly one
  candidate/role is chosen; server-provided preview URLs only; component identity
  shown in each review; refetch after success; URL-persisted internal component
  filter; DLC/expansion card prohibits `window.open` fallback.
- Blocking proof: component and local-art Vitest suites prove no apply before
  choice, route query lands on the matching manifest, and DLC activation never
  invokes the external link path.
  </threat_model>
