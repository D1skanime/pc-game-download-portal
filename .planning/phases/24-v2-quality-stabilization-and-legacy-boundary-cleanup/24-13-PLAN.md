<ui_operation_taxonomy>

The UI must distinguish operation scope from operation intent. Use stable translated names and descriptions for: Library scan, Platform scan, ROM refresh, Metadata-only refresh, Media-only refresh, Hash recalculation, Unmatched ROMs, Complete rescan, Manual match, and PC parent/DLC/expansion matching. The same intent must use the same label and behavior in every entry point; only the scope may differ. Metadata-only must not silently fetch or replace media, and media-only must not silently replace text metadata. Provider selection, requested metadata locale, actual provider locale, and fallback must remain visible in the operation summary.
