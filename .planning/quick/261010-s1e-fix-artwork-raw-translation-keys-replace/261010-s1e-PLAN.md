# Quick Task Plan

**Task:** 261010-s1e

**Goal:** Replace the visible raw `rom.upload-artwork` text on the Artwork media surface with proper localized UI labels in every supported locale.

**Diagnosis:** `frontend/src/v2/components/GameDetails/ArtworkSubtab.vue` already routes the upload button, dropzone title, and dropzone input label through `t("rom.upload-artwork")`, but the key is absent from every `frontend/src/locales/*/rom.json`. Vue i18n therefore renders the key itself. The existing locale parity checker compares every non-English locale against `en_US`, so the new key must be present in all locale files. No component, API, permission, upload, or media architecture change is needed.

**Scope:** Reuse the existing `rom` namespace, current sorted JSON locale format, and the existing `ArtworkSubtab` upload flow. Add only the missing translation entries and focused verification. Use a natural localized label for German (`Artwork hochladen`) and English (`Upload artwork`); for locales without a maintained translation in this quick task, use the repository's existing English fallback convention while preserving key parity. Do not change `ArtworkSubtab.vue` unless verification proves the existing translation call itself is wrong. Do not alter provider artwork, deletion, placement, permissions, or upload behavior.
