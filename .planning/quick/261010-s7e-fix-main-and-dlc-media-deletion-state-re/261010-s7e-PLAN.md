**Task:** 261010-s7e

**Goal:** Make successful owned-media deletion immediately and reliably disappear from both the main game's Media surface and the PC DLC Media surface, with clear localized success feedback. Replace the DLC card's raw technical role/MIME presentation with useful localized media labels and source information.

**Diagnosis:** Main ScreenshotsSubtab.vue and ArtworkSubtab.vue already call the canonical romsStore.refreshRom after DELETE, but tests do not prove that the deleted item is absent after the refresh. PcDlcMediaTab.vue calls local load() and emits refresh; PcDlcDetails.vue can then resolve the parent from romsStore.currentRom without fetching it again. The schema already exposes origin and provider, so the card can show a localized role plus useful source/provider information without changing the media architecture.

**Scope:** Main parent media deletion state in ScreenshotsSubtab.vue and ArtworkSubtab.vue; DLC media deletion and parent refresh flow in PcDlcMediaTab.vue, PcDlcDetails.vue, and only the supporting store/API path needed to force fresh state; focused tests; locale entries for new DLC media labels and deletion-success messages. Reuse existing DELETE endpoints, expected-version handling, confirmations, permission gates, canonical refresh, load(), snackbar, and i18n. Do not change backend deletion, storage, placement semantics, or unrelated MIME consumers.
