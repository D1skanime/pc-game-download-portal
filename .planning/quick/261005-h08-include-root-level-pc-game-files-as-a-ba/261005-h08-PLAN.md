# Include root-level PC files in the base download component

## Objective

Make a directory-backed Windows ROM expose its direct game files as one
immutable `base` component. This lets the existing component sync and download
manifest path include a file such as `The Witcher 3 Wild Hunt.iso` together
with its nested expansion archives, without changing ordinary ROM-file
categorization or the established component layout rules.
