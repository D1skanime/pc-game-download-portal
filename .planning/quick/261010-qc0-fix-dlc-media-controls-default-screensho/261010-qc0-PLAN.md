- Artwork/screenshot selection changes DLC cards and empty state; default is screenshots.
- Parent Media opens on Screenshots, not Manual/Handbook.
- Authorized users can delete media and add/remove that exact DLC card from its Overview; removing placement preserves media bytes.
- DLC Overview shows only its active component-local placements in persisted order, with no parent/sibling leakage and inherited parent background unchanged.
- Read-only and stale-version behavior remains safe.
- Game Download keeps metadata search visible and correctly ordered for matchable components, with existing matcher targets and download selection intact.
- Focused backend/frontend tests and typecheck pass; provider credential absence is reported only as an environment blocker.
